# HTTP Cache FAQ {#http-cache-faq}

Short answers for setup and common cache misses.

> **Prerequisites:** [HTTP Cache Package](README.md)

## Getting Started {#getting-started}

### Do I need to register the filter manually? {#manual-filter-registration}

No. Normal installs discover `Switon\HttpCache\Filter\PageCacheFilter` automatically through listener metadata, but
`PageCacheFilter` still has to be enabled in `RequestHandler.filters`.

### How do I enable page caching for one action? {#enable-caching}

Add `#[PageCache]` to the action and set a TTL.

The default TTL is `3` seconds.

### What should I cache with this package? {#what-to-cache}

Use it for one action's final response body when repeated requests should reuse the same output.

## Configuration {#configuration}

### Where do I configure page cache options? {#configure-filter}

Use `switon.yml` with `Switon\HttpCache\Filter\PageCacheFilter`.

### How do I use a separate Redis client? {#configure-redis}

Define a named `Switon\Redis\ClientInterface` client and point `redisCache` at it.

If you do not override `prefix`, the default is `cache:{app_id}:page_cache:`.

### How do I inspect the current Redis options? {#discover-options}

Run `bash bin/console config:options 'Switon\Redis\ClientInterface'`.

## Cache Keys {#cache-keys}

### How are keys generated by default? {#default-key-generation}

The default key is the controller action itself.

### How do I narrow the key? {#custom-key-params}

Use the `key` argument in `#[PageCache]`.

### Why am I getting the wrong page variant? {#wrong-variant}

Usually one output-changing value is missing from the key.

## Troubleshooting {#troubleshooting}

### Cache is not being used. What should I check first? {#cache-not-used}

Check `#[PageCache]`, the request method, `ttl`, `200` status, and Redis keys.

Remember that `POST` is eligible too, so a cache hit can happen on POST when the key matches.

### Why do `304` responses not appear? {#missing-304}

The client must send `If-None-Match`, and the cached `ETag` must still match.

The cache also stores gzip bodies; if the client advertises gzip, the cached body can be served compressed.

### Why does JSON seem to miss the HTML cache? {#json-variant}

That is expected. JSON requests use a separate variant.
